# Firebase — Ministério de Louvor Casa do Oleiro

Projeto Firebase: igreja-casa-do-oleiro-2e2fb

## Ativação inicial

1. Firebase Console > Authentication > Sign-in method > E-mail/senha: ativar.
2. Firebase Console > Firestore Database > Criar banco de dados.
3. Escolher modo de produção.
4. Em Rules, colar o conteúdo de firestore.rules e publicar.

O front-end continua hospedado no GitHub Pages. O Firebase é usado para login, Firestore e auditoria inicial.
